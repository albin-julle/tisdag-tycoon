# Tisdag Tycoon

Ett litet tycoon-spel i 3D (Three.js) där man driver Tisdag Tryckeri – ta order vid disken, tryck, skär och leverera, och bygg upp maskinparken.

- `index.html` – spelet
- `lokal.html` – lokalen att titta runt i
- `maskiner.html` – maskinparken i 3D
- `models.js` – alla 3D-modeller (byggda i kod)
- `lokal.js` – planlösningen
- `assets/` – Tisdags logga

Allt är statiska filer, så sidan kan publiceras direkt (t.ex. GitHub Pages) utan byggsteg. Three.js laddas från jsDelivr.
